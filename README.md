# 🧪 Python Data Types 

In Python, **data types** define what kind of value a variable holds.
The 4 most common data types for beginners are:
- `str` – Strings (text)
- `int` – Integers (whole numbers)
- `float` – Decimal numbers
- `bool` – Booleans (True/False)

Knowing data types helps you write better code and avoid errors.

---

## 💻 Example with Explanation

```python
name = "Alice"          # str
age = 30                # int
height = 1.65           # float
is_coding = True        # bool

print(name)
print(age)
print(height)
print(is_coding)
```

### 🔈 Output

```
Alice
30
1.65
True
```

---

### 📌 Key Notes

- Strings go in quotes: `"text"`
- Integers are whole numbers: `5`, `42`
- Floats have decimal points: `3.14`, `0.5`
- Booleans are either `True` or `False`
- Python detects the data type based on the value

Use `type()` to check a variable's data type:
```python
print(type(name))   # <class 'str'>
```
